## 前置条件

- 机型：红米 Note 12 Pro 5G / Note 12 Pro+ 5G（代号 `ruby`）
- 内核：非 GKI 的 4.19「四系」内核
- 系统：MIUI / 澎湃 OS，**不适用于 AOSP 类原生系统**
